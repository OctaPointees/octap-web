# Landing Page for OctaP

Vite + React + Tailwind v4 implementation of the **V4b Magenta Pulse** design
(`.kombai/canvas/octap_landing.canvas`). Each landing section is a component in `src/sections/`.

```bash
npm run dev:landing   # from the repo root, http://localhost:3000
```

The design uses its own magenta palette (`src/index.css`) and does not load the shared daisyUI `octap` theme.
Partner names, quotes, press mentions and milestone numbers are fictional demo content.
